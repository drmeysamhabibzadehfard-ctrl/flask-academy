# آکادمی آموزشی Flask

پروژه نمونه یک سایت آموزش آنلاین فارسی با Flask، SQLAlchemy، Flask-Login و Bootstrap 5 RTL.

## اجرا

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
python app.py
```

سپس:
http://127.0.0.1:5000
